# Hola, soy Marcos Chicote Matamala

Administrador de sistemas y especialista en ciberseguridad, con interés en
la construcción, administración y protección de sistemas útiles, seguros y
respetuosos con la privacidad.

Actualmente trabajo y aprendo alrededor de Linux, redes, virtualización,
servicios autoalojados y automatización. También desarrollo proyectos web y
mantengo un homelab con Docker y Tailscale para experimentar con tecnologías
open source y documentar lo que aprendo.

## En qué estoy trabajando

- Administración de servidores Linux y Windows Server.
- Redes, virtualización y fundamentos de ciberseguridad.
- Servicios autoalojados con Docker, Nginx y Tailscale.
- Desarrollo de interfaces web con HTML, CSS, JavaScript, TypeScript y Astro.
- Documentación técnica y automatización de tareas.
